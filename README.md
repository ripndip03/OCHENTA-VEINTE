# Ochenta - Veinte

Web del estudio de tatuajes Ochenta - Veinte. Es una web estática (HTML + CSS), sin compilación.

- `index.html`: la página
- `styles.css`: los estilos (colores en `:root`)
- `video/`: vídeos de fondo (portada y banda del mural)
- `img/`: fotos del estudio

Se publica en Vercel automáticamente con cada cambio en la rama `main`.
